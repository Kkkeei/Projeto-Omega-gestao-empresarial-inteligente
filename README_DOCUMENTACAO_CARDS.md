# ÔMEGA — Documentação por Cards

A página interna da documentação de cada empresa foi organizada no mesmo padrão de interação da Central de Certidões:

1. No topo aparecem exatamente 3 cards:
   - Pessoal (Sócio)
   - Societário
   - IRPF
2. Ao clicar em um card, ele fica selecionado.
3. Logo abaixo é exibido um único painel com o conteúdo da pasta selecionada.
4. O painel selecionado contém:
   - nome da pasta;
   - quantidade de documentos;
   - botão Adicionar documento;
   - tabela/lista dos documentos;
   - Visualizar, Baixar e Histórico;
   - nova versão pelo histórico.
5. Trocar o card troca o conteúdo exibido abaixo sem navegar para outra página.

A estrutura de banco e os endpoints de Documentação permanecem os mesmos.
