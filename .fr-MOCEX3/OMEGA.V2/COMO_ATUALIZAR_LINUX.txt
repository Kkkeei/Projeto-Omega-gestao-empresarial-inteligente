OMEGA - CERTIFICADOS E NFS-e CORRIGIDOS (Linux Mint)

1. Faça uma cópia de segurança da pasta atual do projeto.
2. Extraia este ZIP em uma pasta temporária.
3. Entre na pasta OMEGA extraída.
4. Copie o conteúdo da pasta OMEGA para a raiz do projeto atual, substituindo os arquivos de código correspondentes.
5. Preserve obrigatoriamente backend/.env, backend/omega.db e o diretório storage. Não substitua esses itens por arquivos do pacote.
6. Backend: ative o ambiente virtual e reinicie o processo FastAPI/Uvicorn.
7. Frontend: entre em frontend, execute npm ci se necessário e depois npm run dev.
8. Atualize o navegador com Ctrl+F5.

Inclui a aba NFS-e, melhorias de Certificados A1/A3, importação/parsing de XML e controle de cursor/erros de persistência.

Verifique docs/CORRECOES_CERTIFICADOS_NFSE_2026-10-13.md para as alterações, testes e limitações.
