OMEGA A3 - INSTALADOR WINDOWS

1. Extraia este ZIP.
2. Execute INSTALAR_OMEGA_A3.bat com duplo clique.
3. O instalador configura o OMEGA A3 para iniciar automaticamente.
4. Depois, conecte o leitor/token e abra o OMEGA.

O usuario nao precisa iniciar o Bridge manualmente.

IMPORTANTE: o driver/middleware do fabricante do certificado A3 (por exemplo SafeSign/SafeNet) precisa estar instalado no Windows para o cartao ser reconhecido.
